# P3R Rainmeter Player

A fan-made Persona 3 Reload-inspired Spotify mini player for Rainmeter.

![Preview](preview.gif)

## Features

- Spotify track title display
- Elapsed playback time
- Persona 3 Reload-inspired LCD design
- Play / Pause / Previous / Next controls
- Always-on-top desktop widget
- Transparent background

## Requirements

- Windows
- Rainmeter
- Spotify Desktop
- RainmeterMediaPlayer
- Long Pixel-7 font

## Installation

1. Install Rainmeter.
2. Install RainmeterMediaPlayer.
3. Install the Long Pixel-7 font.
4. Download this repository.
5. Copy the `P3RPlayer` folder to:

   `Documents\Rainmeter\Skins\`

6. Refresh Rainmeter.
7. Load `P3RPlayer.ini`.

## Recommended Rainmeter Settings

Right-click the skin:

- Settings → Position → Stay Topmost
- Settings → Click through
